# Simple Chatbot with Knowledge Base and Appointment Handling

![Chatbot Demo](https://img.shields.io/badge/Demo-Available-green) ![Python](https://img.shields.io/badge/Python-3.7%2B-blue) ![License](https://img.shields.io/badge/License-MIT-orange)

A multilingual chatbot designed for hospital reception services with appointment scheduling, voice interaction, and secure data handling capabilities.

## Features

- **Multilingual Support**: English, French, Spanish, Hindi, and Japanese
- **Voice Interaction**: Speech-to-text and text-to-speech functionality
- **Appointment Management**: Book, reschedule, and cancel appointments
- **Knowledge Base**: Answers predefined questions about hospital services
- **Data Security**: Encrypted storage for visitor information
- **PDF Reports**: Automatic generation of appointment confirmation PDFs
- **Admin Panel**: Secure access to visitor data
